1. Hukuk dosyası
Açık
Aşama seçenekleri

- Derdest
- Karar verildi
- Gerekçeli karar bekleniyor
- Gerekçeli karar tebliğ edildi
- İstinaf incelemesi
- Temyiz incelemesi
- Bozma / Kaldırma sonrası yeniden yargılama
- Kesinleşti

Kapalı
Kapanma seçenekleri

- Davanın tamamen kabulü (kesinleşti)
- Davanın kısmen kabulü (kesinleşti)
- Davanın esastan reddi (kesinleşti)
- Davanın usulden reddi (kesinleşti)
- Feragat nedeniyle sonuçlandı
- Davalının kabulü nedeniyle sonuçlandı
- Sulh nedeniyle sonuçlandı
- Konusuz kaldı / Karar verilmesine yer olmadığı
- Davanın açılmamış sayılması
- Başka dosyayla birleştirildi
- Görevsizlik nedeniyle başka mahkemeye aktarıldı
- Yetkisizlik nedeniyle başka mahkemeye aktarıldı
- Diğer (Tüm diğerlere kullanıcı açıklama yazmalı)

- Uzlaşma nedeniyle düşme
- Zamanaşımı nedeniyle düşme

- Ön ödeme nedeniyle düşme
- Başka dosyayla birleştirildi
- Görevsizlik nedeniyle başka mahkemeye aktarıldı
- Yetkisizlik nedeniyle başka mahkemeye aktarıldı
- Diğer

3. İdari yargı dosyası
Açık
Aşama seçenekleri

- Derdest
- Karar verildi
- Gerekçeli karar bekleniyor
- Gerekçeli karar tebliğ edildi
- İstinaf incelemesi
- Temyiz incelemesi
- Bozma / Kaldırma sonrası inceleme
- Kesinleşti

Kapalı
Kapanma seçenekleri

- İptal kararı (kesinleşti)
- Kısmen iptal kararı (kesinleşti)
- Davanın esastan reddi (kesinleşti)
- Davanın usulden reddi (kesinleşti)
- Tam yargı davasının kabulü (kesinleşti)
- Tam yargı davasının kısmen kabulü (kesinleşti)
- Feragat nedeniyle sonuçlandı
- Konusuz kaldı / Karar verilmesine yer olmadığı
- Davanın açılmamış sayılması
- Görevsizlik / Yetkisizlik nedeniyle aktarıldı
- Başka dosyayla birleştirildi
- Diğer

4. İcra dosyası
Açık
Aşama seçenekleri

- Takip başlatıldı
- Ödeme / İcra emri düzenlendi
- Ödeme / İcra emri tebliğ edildi
- Takip durdu
- Takip kesinleşti
- Haciz aşaması
- Satış / İhale aşaması
- Kısmi tahsilat
- Dosya işlemsiz / Pasif

Kapalı
Kapanma seçenekleri

- Borcun tamamen tahsili / İnfazen kapandı
- Haricen tahsil nedeniyle kapandı
- Takipten vazgeçildi
- Takip iptal edildi
- İcra emri / Takip iptali kararı uygulandı
- Alacaklı talebiyle kapatıldı
- İlgili takip sona erdi
- Başka dosyaya aktarıldı / Birleştirildi
- Diğer

5. Soruşturma dosyası
Açık
Aşama seçenekleri

- Suç duyurusu / Şikâyet yapıldı
- Soruşturma devam ediyor
- Kamu davasının açılmasının ertelenmesi
- İddianame düzenlendi
- KYOK kararı verildi
- KYOK kararına itiraz incelemesi

Kapalı
Kapanma seçenekleri

- KYOK kesinleşti
- İddianame kabul edildi / Ceza davasına aktarıldı
- Uzlaştırma sonucunda KYOK
- Ön ödeme sonucunda KYOK
- Kamu davasının açılmasının ertelenmesi sonrasında KYOK
- Seri muhakeme usulüyle sonuçlandı
- Başka soruşturmayla birleştirildi
- Yetkisizlik nedeniyle aktarıldı
- Diğer

6. Sözleşme dosyası
Açık
Aşama seçenekleri

- Taslak
- Müzakere
- Revizyon
- Müvekkil onayı bekleniyor
- Karşı taraf onayı bekleniyor
- İmza bekleniyor
- Noter / Resmî işlem aşaması
- İmzalandı / Yürürlükte

Kapalı
Kapanma seçenekleri

- İmzalandı / Hazırlama işi tamamlandı
- İfa edilerek sona erdi
- Süresi doldu
- Tarafların anlaşmasıyla sona erdi
- Feshedildi
- Sözleşme kurulamadı
- Müzakereler sonuçsuz kaldı
- Hazırlanmaktan vazgeçildi
- Diğer

7. Arabuluculuk dosyası
Açık
Aşama seçenekleri

- Başvuru yapıldı
- Arabulucu atandı
- Görüşmeler devam ediyor
- Anlaşma metni hazırlanıyor
- Son tutanak hazırlanıyor
- İcra edilebilirlik şerhi işlemleri

Kapalı
Kapanma seçenekleri

- Tam anlaşma
- Kısmi anlaşma
- Anlaşamama
- Arabuluculuğa elverişli olmadığı tespit edildi
- Diğer

8. İhtarname dosyası
Açık
Aşama seçenekleri

- Taslak
- Müvekkil onayı bekleniyor
- Noter işlemleri
- İhtarname gönderildi
- Tebligat bekleniyor
- Tebliğ edildi / Cevap bekleniyor
- Verilen sürenin dolması bekleniyor
- Cevap inceleniyor
- Müzakere devam ediyor
- Yeniden tebligat işlemleri

Kapalı
Kapanma seçenekleri

- Tebliğ edildi / İşlem tamamlandı
- Cevap alındı / İşlem tamamlandı
- Süre doldu / İşlem tamamlandı
- Talep yerine getirildi
- Taraflar anlaştı
- Tebliğ edilemedi / İşlem sonlandırıldı
- İhtarname gönderilmesinden vazgeçildi
- Dava / İcra sürecine aktarıldı
- Diğer

9. Diğer dosyalar
Açık
Aşama seçenekleri

- Hazırlık
- Belge / Bilgi bekleniyor
- Başvuru yapıldı
- İşlem devam ediyor
- Karşı taraf / Kurum cevabı bekleniyor
- Onay bekleniyor
- Sonuçlandırma aşaması

Kapalı
Kapanma seçenekleri

- Tamamlandı
- Olumlu sonuçlandı
- Olumsuz sonuçlandı
- Anlaşmayla sonuçlandı
- Vazgeçildi
- İşlem yapılamadı
- Başka dosyaya aktarıldı
- Diğer
